# 附录 · 策略参考 · 海龟交易法则（入场 / 加仓 / 止损 / 离市）

> 主文档：../../design.md · 版本随 v0.4 同步

## 四、双系统入场规则

海龟同时运行**两个独立的唐奇安通道系统**，用以捕捉不同级别的趋势。

### 4.1 系统1（System 1）——短期趋势

| 规则 | 说明 |
| --- | --- |
| **多头入场** | 价格向上突破**20日**最高价 |
| **空头入场** | 价格向下跌破**20日**最低价 |
| **离市** | 多头跌破**10日**最低价 / 空头涨破**10日**最高价 |
| **过滤规则** | 若上一次同方向突破是**盈利**的，则跳过本次信号 |

**跳过滤波（Skip Rule）的解释**：如果上一次系统1的同方向突破交易最终是盈利退出的，说明趋势可能已经走得较远，此时再入场风险较高，因此跳过本次信号。这个过滤器的目的是**避免在已经运行了一段趋势后追高**。

### 4.2 系统2（System 2）——长期趋势

| 规则 | 说明 |
| --- | --- |
| **多头入场** | 价格向上突破**55日**最高价 |
| **空头入场** | 价格向下跌破**55日**最低价 |
| **离市** | 多头跌破**20日**最低价 / 空头涨破**20日**最高价 |
| **过滤规则** | **无**跳过滤波，每个突破信号都被执行 |

### 4.3 入场执行细节

海龟总是在**突破发生的当下立即入市交易**，不会等到当日收盘或次日开盘。在跳空开盘的情况下，如果开盘价已经跳过了突破价，海龟在**开盘时**入市。

## 六、金字塔加仓规则

### 6.1 加仓条件

当价格继续朝有利方向移动时，海龟进行**金字塔式加仓**：

- 价格每朝有利方向移动 **0.5×N**，加仓1个单位
- 加仓以上一笔订单的**实际成交价格**为基础计算
- 最大持仓不超过**4个单位**

### 6.2 加仓示例（多头）

假设：
- 初始入场价：100
- N值：10

| 加仓顺序 | 触发价格 | 累计单位 |
| --- | --- | --- |
| 第1单位（初始） | 100（突破入场） | 1 |
| 第2单位 | 100 + 0.5×10 = 105 | 2 |
| 第3单位 | 105 + 0.5×10 = 110 | 3 |
| 第4单位 | 110 + 0.5×10 = 115 | 4 |

> **注意**：原版海龟对加仓**没有时间间隔限制**（如"每5个交易日"等），只要价格达到条件即可操作。

## 七、止损规则

### 7.1 硬性止损（Hard Stop）

每个单位在入场时即设置硬止损：

| 方向 | 止损价 |
| --- | --- |
| **多头** | 入场价 - **2×N** |
| **空头** | 入场价 + **2×N** |

这意味着**单个单位**的最大亏损正好是账户净值的 **1%**（因为单位大小本身就是按1%风险计算的）。

### 7.2 阶梯式止损（随加仓调整）

当金字塔加仓后，**之前头寸单位的止损点会相应调整**。

**逐笔止损法**（原版方式）：
- 第1个单位止损价 = 入场价₁ - 2×N
- 第2个单位止损价 = 入场价₂ - 2×N（比第1个高0.5×N）
- 以此类推

**均价止损法**（简化方式）：
```
止损价 = 持仓均价 - 2×N + (持仓单位数 - 1) × 0.5×N
```

### 7.3 双重损失（备选止损策略）

原版海龟还提供了一个备选止损策略——**双重损失**：如果价格从最高点回撤了**2×N**，全部平仓。

## 八、离市规则（止盈）

海龟对盈利头寸使用**以突破为基础的离市策略**——**不提前止盈，让利润奔跑直到趋势反转**。

| 系统 | 多头离市 | 空头离市 |
| --- | --- | --- |
| **系统1** | 价格跌破**10日**最低价 | 价格涨破**10日**最高价 |
| **系统2** | 价格跌破**20日**最低价 | 价格涨破**20日**最高价 |

> **重要澄清**：**"10日/20日反向突破"是离市信号（止盈/清仓）**，而 **"2×N止损"是风控信号（砍仓）**。两者哪个先触发，就以哪个为准。
