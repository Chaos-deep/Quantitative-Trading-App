## 五、仓位管理（头寸规模）

### 5.1 核心理念

头寸规模是海龟交易系统**最重要的部分之一**。其核心优势是**根据市场的绝对波动幅度来调整头寸规模**，将不同市场、不同波动率品种的头寸风险**标准化**。

> **波动率越高的市场，持仓越少；波动率越低的市场，持仓越多。** 市场的波动性与头寸规模相互抵消。

### 5.2 单位（Unit）计算公式

**原版公式**（适用于期货等有合约乘数的品种）：

```
单位数量 = (账户净值 × 1%) / (N × 每点价值)
```

其中：
- **账户净值 × 1%**：单笔交易愿意承担的最大风险金额
- **N**：20日ATR（点数）
- **每点价值**：该合约每波动1个点对应的货币价值

**简化公式**（适用于A股等无合约乘数的品种）：

```
单笔交易股数 = 账户净值 × 1% ÷ N
```

> **本质**：用N将不同波动率的品种标准化，使不同品种的单笔交易在风险敞口上相当。一个单位的头寸，其每日波动幅度约为账户净值的1%。

### 5.3 计算示例

假设某期货品种：
- 账户净值：100万美元
- N值（20日ATR）：500点
- 每点价值：10美元

```
单位数量 = (1,000,000 × 1%) / (500 × 10) = 10,000 / 5,000 = 2手
```

### 5.4 最大持仓限制

| 限制 | 数量 |
| --- | --- |
| **单个品种** | 最多**4个单位** |
| **高度相关市场** | 合计最多**6个单位** |
