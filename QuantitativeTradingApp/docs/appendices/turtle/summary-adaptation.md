# 附录 · 策略参考 · 海龟交易法则（总结与 A 股适用性）

> 主文档：../../design.md · 版本随 v0.4 同步

## 九、策略特点总结

### 9.1 海龟交易系统一览表

| 规则 | 系统1 | 系统2 |
| --- | --- | --- |
| **入场周期** | 20日突破 | 55日突破 |
| **离市周期** | 10日反向突破 | 20日反向突破 |
| **跳过滤波** | 有（上次盈利则跳过） | 无 |
| **单笔风险** | 账户1%（基于ATR） | 相同 |
| **加仓方式** | 每0.5×N，最多4单位 | 相同 |
| **硬止损** | 入场价 ± 2×N | 相同 |

### 9.2 优势

| 优势 | 说明 |
| --- | --- |
| **趋势收益高** | 抓住大趋势时收益可观，历史上年化收益可达24%-80% |
| **风险可控** | N值动态调整仓位，2×N硬止损锁定单笔风险 |
| **完全机械化** | 规则覆盖所有决策，消除情绪干扰 |
| **适应性强** | 可应用于期货、股票、外汇、加密货币等多市场 |

### 9.3 劣势

| 劣势 | 说明 |
| --- | --- |
| **胜率低** | 典型趋势跟踪策略特征——**胜率低**，靠少数大盈利覆盖多次小亏损 |
| **回撤大** | 震荡行情中连续止损可能导致较大回撤 |
| **交易成本高** | 频繁突破交易产生手续费 |
| **需要耐心** | 可能长时间无信号或连续亏损 |

## 十、在A股市场的适用性分析

### 10.1 A股的特殊限制

| 限制 | 对海龟策略的影响 |
| --- | --- |
| **T+1制度** | 当日买入无法当日卖出，止损需延迟至次日执行 |
| **无法做空** | 只能执行多头策略，无法利用空头趋势 |
| **涨跌停板** | 突破信号可能因涨停/跌停而无法执行 |
| **A股趋势持续性弱** | 相比期货，A股趋势持续性较弱，假突破更多 |

### 10.2 A股适应性改造建议

| 改造点 | 原版（期货） | A股改进版 | 原因 |
| --- | --- | --- | --- |
| **突破价格** | 最高/最低价 | **收盘价突破** | T+1制度下盘中追高无法当日卖出 |
| **入场周期** | 20日/55日 | 可考虑**55日**为主 | A股假突破多，放大周期过滤噪音 |
| **止损时机** | 当日触及即止损 | **次日开盘止损** | T+1制度限制 |
| **品种选择** | 高流动性期货 | **高流动性ETF/龙头股** | 避免流动性不足和停牌风险 |

### 10.3 适用标的建议

A股市场中，以下品种较适合海龟策略：
- **宽基ETF**：沪深300ETF（510300）、创业板ETF（159915）——流动性好、趋势相对明显
- **行业ETF**：券商ETF、半导体ETF——波动大、趋势性强
- **龙头个股**：需注意流动性和停牌风险
