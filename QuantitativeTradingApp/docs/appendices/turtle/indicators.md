## 三、核心指标

### 3.1 N值（即ATR）

海龟使用 **"N"** 来表示某个市场的根本波动性，N是**真实波动幅度（True Range, TR）的20日指数移动平均值**，即20日ATR。

**第一步：计算True Range（TR）**

```
TR = MAX（当日最高价 - 当日最低价，
        |当日最高价 - 前一日收盘价|，
        |当日最低价 - 前一日收盘价|）
```

TR的计算覆盖了三种市场情况：
- **正常情况**：当日最高 - 当日最低
- **跳空高开**：当日最高 - 前收
- **跳空低开**：前收 - 当日最低

**第二步：计算N值（20日ATR）**

```
N = (前19日TR之和 + 当日TR) / 20
```

或使用Wilder平滑方式：
```
N_t = (N_{t-1} × 19 + TR_t) / 20
```

### 3.2 唐奇安通道（Donchian Channel）

海龟使用**唐奇安通道**来捕捉突破信号。

| 轨道 | 计算方法 |
| --- | --- |
| **上轨** | 过去N日最高价的最大值 |
| **下轨** | 过去N日最低价的最小值 |
| **中轨** | (上轨 + 下轨) / 2 |

当价格冲破上轨时，产生买入信号；冲破下轨时，产生卖出信号。
