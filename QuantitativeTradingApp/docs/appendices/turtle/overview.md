# 附录 · 策略参考 · 海龟交易法则（起源与哲学）

## 一、起源与背景

### 1.1 海龟实验

1983年，著名商品期货交易员**理查德·丹尼斯（Richard Dennis）** 与搭档**威廉·埃克哈特（William Eckhardt）** 就一个核心问题产生分歧：**伟大的交易员是天生的，还是后天培养的？**

为了验证这一命题，丹尼斯在《华尔街日报》刊登广告，从数千名申请者中招募了23名背景各异的普通人，进行了为期两周的密集培训。这批学员被称为 **"海龟"（Turtles）** ——丹尼斯解释说，这就像在新加坡人们被培养成海龟一样。

培训内容是一套完整的、机械化的趋势跟踪交易系统。培训结束后，丹尼斯给每位学员分配了100万美元的真实资金进行实战交易。

### 1.2 实验结果

在随后的四年中，海龟们取得了**年均复利80%** 的惊人收益。其中表现最出色的学员**柯蒂斯·费思（Curtis Faith）**，19岁加入实验，在4年内为丹尼斯赚取了3150万美元。

这一实验证明了：**用一套简单的系统和严格的规则，可以使很少或根本没有交易经验的人成为优秀的交易员**。

### 1.3 法则的公开

原版海龟法则曾被约定保密10年（至1993年）。2003年，柯蒂斯·费思将完整的海龟交易法则公之于众，自此成为全球量化交易和趋势跟踪领域最经典的教材之一。

## 二、核心哲学思想

### 2.1 趋势跟踪（Trend Following）

海龟交易法则的核心逻辑是：**"当价格突破过去的高点，买入并持有；趋势持续时加仓；当趋势反转时平仓退出。"**

系统**不预测市场方向**，而是等待市场给出明确的方向信号后顺势入场。其基本假设是：**趋势一旦形成，往往会延续**。

### 2.2 三大核心理念

| 理念 | 含义 |
| --- | --- |
| **斩断亏损，让利润奔跑** | 亏损时快速出局，盈利时持有至趋势结束 |
| **机械化和纪律性** | 严格执行规则，消除情绪干扰 |
| **风险控制第一** | 每笔交易风险控制在账户的固定比例内 |

### 2.3 完整交易系统的六个要素

海龟交易系统是一个**完整的交易系统**，覆盖了交易的各个方面，不给交易员留下任何主观决策的余地：

| 要素 | 问题 |
| --- | --- |
| **市场** | 买卖什么？ |
| **头寸规模** | 买卖多少？ |
| **入市** | 何时买卖？ |
| **止损** | 何时退出亏损的头寸？ |
| **离市** | 何时退出盈利的头寸？ |
| **策略** | 如何买卖？ |
