## 十三、实盘注意事项

1. **严格执行**：海龟策略成功的关键在于**纪律**，而非预测准确率
2. **滑点控制**：趋势行情中成交价可能偏离信号价，需预留滑点空间
3. **资金规模**：账户需足够大，避免单笔交易对账户冲击过大
4. **品种分散**：在多个低相关性品种上分散执行，降低单一品种风险
5. **回测验证**：实盘前务必进行充分的历史回测
6. **心理准备**：需接受30%-40%的胜率和较大的资金回撤

**免责声明**：本文档仅供学习研究参考，不构成任何投资建议。量化交易存在风险，实盘使用前请充分测试并谨慎评估。
